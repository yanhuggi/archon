= JDBSEE CLI
Davide Cavestro <https://github.com/davidecavestro[@davidecavestro]>

:toc:

JDBSee CLI is a command-line JDBC client derived from
https://github.com/davidecavestro/jdbsee[davidecavestro/jdbsee]. This repository
maintains the 2.1.1 fork and its
link:skills/jdbsee/SKILL.md[JDBSee database integration skill].

== Features

* Execute read-only SQL with `query`, with JSON, Markdown, or CSV output.
* Execute validated DDL/DML with `execute`.
* Register JDBC drivers and reusable connection aliases.
* Inspect tables, views, and driver metadata with `schema`.
* Encrypt persisted alias passwords with AES-256-GCM.
* Expose database tools through an MCP HTTP/SSE server.
* Resolve JDBC drivers from Maven dependencies, explicit JARs, or `dropins`.

== Commands

[cols="1,3"]
|===
|Command |Purpose

|`query`
|Run a validated read-only `SELECT` query.

|`execute`
|Run validated `INSERT`, `UPDATE`, `DELETE`, `CREATE`, `ALTER`, or `DROP` statements.

|`driver`
|Create, list, inspect, and delete persistent JDBC driver definitions.

|`alias`
|Create, list, inspect, and delete persistent connection aliases.

|`schema`
|List tables/views or show JDBC driver metadata.

|`mcp`
|Start the MCP HTTP/SSE server.

|`help`
|Print command help.
|===

Run `jdbsee --help` or `jdbsee COMMAND --help` for the complete option list.

== Examples

=== Query with an on-demand driver

[source,shell]
----
jdbsee query \
  -d "org.postgresql:postgresql:42.2.1" \
  -c "org.postgresql.Driver" \
  -l "jdbc:postgresql://localhost:5432/test" \
  -u postgres -p postgres \
  "SELECT * FROM contacts"
----

=== Execute DDL/DML

[source,shell]
----
jdbsee execute -a testdb \
  "UPDATE contacts SET active = true WHERE id = 1"
----

=== Register and reuse a connection

[source,shell]
----
jdbsee driver create h2 \
  -d "com.h2database:h2:1.4.196" \
  -c "org.h2.Driver"

jdbsee alias create h2 local \
  "jdbc:h2:file:/tmp/jdbsee-example" \
  -u sa -p ""

jdbsee query -a local "SELECT 1 AS value"
----

=== Start MCP

[source,shell]
----
jdbsee mcp start --port 8080 --alias local
----

== Build And Test

Java 8 or newer is required.

[source,shell]
----
./mvnw clean verify
./mvnw clean package
----

The runnable distribution is created under `target/distribution`.
The base archives are written to `target/jdbsee-2.1.1.zip` and
`target/jdbsee-2.1.1.tar`.

To create the full distribution with bundled JDBC drivers:

[source,shell]
----
./mvnw clean package -Pfull-distribution
----

The full archives are written to `target/jdbsee-full-2.1.1.zip` and
`target/jdbsee-full-2.1.1.tar`.

== Configuration

User settings are stored under `$HOME/.jdbsee`:

* `data/` contains the HSQLDB-backed driver and alias settings.
* `.master.key` contains the owner-only encryption key for alias passwords.
* `dropins/` may contain JDBC driver JARs.

The generated launchers automatically use their installed distribution as the
application home, so its `dropins/` folder is available from any working
directory. Set `JDBSEE_HOME` to override that location when needed.
